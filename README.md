# LP Agostinho — MFX Creativee

Landing page mobile-first para venda do serviço de Landing Pages prontas em até 72h.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — estilos mobile-first
- `script.js` — menu, WhatsApp e animações
- `assets/` — coloque aqui imagens, prints, favicon e OG image

## Antes de publicar

1. O WhatsApp já está configurado com o número:
   ```js
   whatsappNumber: "5534984187265"
   ```

2. Todos os botões já têm mensagens diferentes para identificar de onde veio o clique.

3. No `index.html`, procure por:
   ```html
   META PIXEL / GOOGLE ANALYTICS / CLARITY
   ```
   e cole seus scripts depois.

4. Troque os placeholders de imagem por imagens reais dentro da pasta `assets`.
